# 🌌 Stellar Merge 2048 (Cosmic Celestial Fusion)

A gorgeous, responsive, cosmic-themed 2048 puzzle game built with pure HTML5, CSS3, and Vanilla JavaScript. Features real-time celestial body fusion, smooth animations, screen shake, touch-swipe & keyboard controls, undo support, and a Web Audio API sound synthesizer with zero external dependencies!

## ✨ Features

- **🪐 11-Tier Celestial Fusion System:**
  - `2`: 🌑 Micro Asteroid
  - `4`: ☄️ Comet Core
  - `8`: 🌙 Lunar Moon
  - `16`: 🔴 Mars Planet
  - `32`: 🌍 Gaia World
  - `64`: 🪐 Ringed Titan
  - `128`: ☀️ Solar Flare
  - `256`: ⚡ Plasma Pulsar
  - `512`: 🌌 Nebula Void
  - `1024`: 🕳️ Black Hole Singularity
  - `2048`: 💥 Cosmic Supernova!
  - `4096+`: ♾️ Hyper Void & Omniverse
- **🎨 Modern Visual Design:**
  - Ambient twinkling celestial starfield canvas animation.
  - Deep cosmic twilight gradient background.
  - Glowing celestial tiles with distinct neon colorways.
  - Smooth 60fps CSS transitions, pop-spawn, and merge-pulse animations.
  - Dynamic screen shake on high-tier merges (128+).
- **🎵 Real-Time Web Audio API Sound Synthesizer:**
  - Pure procedural audio generated directly by the browser (zero audio files needed).
  - Melodic pitch-scaling merge chimes (scales dynamically with celestial level).
  - Kinetic slide swoosh, cosmic victory fanfare, and game-over chord sequence.
  - One-click sound mute/unmute toggle.
- **📱 Fully Responsive & Touch Friendly:**
  - 100% playable on smartphones, tablets, and desktop displays.
  - Smooth touch swipe gesture detection (`touchstart` / `touchend`).
  - Full keyboard support: **Arrow keys** and **WASD**.
- **↩️ Undo Move & Auto-Save:**
  - 1-step undo move functionality.
  - High score automatically persisted across sessions via `localStorage`.
- **🚫 Zero External AI API Keys & Zero Dependencies:**
  - Operates completely client-side and offline.
  - Requires no AI API key, subscription, account, or external backend.

## 🎮 How to Play

1. Slide the celestial tiles using **Arrow Keys**, **WASD**, or **Touch Swiping**.
2. When two identical celestial bodies collide, they fuse into a higher-tier star!
3. Merge your way up to achieve the legendary **2048 Cosmic Supernova**!
4. After achieving 2048, choose to continue playing indefinitely to explore the Hyper Void.

---

## 🛠️ How to Play Locally

Simply open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari). No server or build step is required!
